# 0002: outcome_attribution page type

Adds the `outcome_attribution` page type for compiled Instagram outcome
signal. The page is generated by `scripts/astory_brain/outcomes.py` from
`data/instagram/carousel_posts/*/carousel_export.json` and ranks posts by
shares per 1k reach plus follow conversion instead of likes. Derived JSON
lives at `references/brain/reports/outcome_attribution.json`.

No changes to existing pages are required.
