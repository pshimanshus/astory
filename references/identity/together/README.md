# Together References

Use together references to preserve relationship energy, body language, height
relationship, posture, and warmth.

- `face-and-body-language/`: everyday couple closeness, body scale, hug/standing/seated poses.
- `formal-secondary/`: wedding/formal context only. Do not use these as everyday defaults.

Together references do not replace solo face anchors from `aachu/face/` and
`zuv/face/`.
