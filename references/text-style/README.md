# Text Style Rules

On-image text must be baked naturally into the illustration.

Rules:
- exact wording
- readable at phone-screen size
- warm charcoal handwritten typography
- placed in upper-middle negative space
- not a digital overlay
- no extra words or random letters
- no speech bubbles unless requested
