# Wardrobe References

Wardrobe references control clothes, accessories, jewelry, shoes, bags, and
other visible styling details.

Folders:

- `aachu/`: Aachu clothing and accessories.
- `zuv/`: Zuv clothing, build, and accessories.
- `couple/`: couple wardrobe combinations and relative scale.

Never use wardrobe references as primary face identity references. If a slide
shows faces, pair wardrobe refs with actual face refs from
`references/identity/*/face/`.
